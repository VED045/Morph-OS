# Phase 7 — advanced launcher MVP

Time-window, charging and low-battery rules are versioned, bounded and start disabled. Enabling is user approval; rules can only select an installed offline theme. WorkManager checks are deferrable (15-minute minimum, OEM delays possible). First matching rule wins; one activation marker prevents repeated revisions and respects manual overrides. Undo restores the earlier design. Home drawer includes grid, list, categories, alphabetical sections, frequent suggestions, search-first and polar/radial views. Radial pages contain eight touchable apps with previous/next/swipe and a list alternative. Search capsule supports up/down gestures; wallpaper supports configurable double tap. Widgets support long-press vertical reordering, scale/rotation controls. Glance visuals never touch secure keyguard. Public launcher-host shortcuts and wallpaper-color accent selection are included.

Final checks after the current changes: 20 unit tests, 7 API 36 instrumentation tests, debug/release lint and both build variants passed. See VERIFICATION.md for the final record. Rule window/midnight/battery/cold-start cases and real radial pagination/list fallback pass. Shortcuts, wallpaper colors, worker/reboot/OEM execution and full gesture/TalkBack acceptance need additional checks. Folders, app drag/drop, app shortcut pin hosting, arbitrary automation actions/widget visibility, free-floating widgets and pinch resizing remain explicit backlog.
